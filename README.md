# Household Budget 3D

Interactive household budget dashboard with a Power BI-style layout and 3D charts (three.js).
Add income and expenses by voice or text, e.g. "I spent 450 on groceries yesterday".

- 3D income vs expenses columns and spending donut
- Budget vs actual per category
- Voice/text commands: add entries, set budgets, ask questions, undo
- Single file: `index.html` (needs internet for the three.js library)
